# Evidence

| Level | What | Use in a pack |
|---|---|---|
| A | Paper / benchmark with public method | May change a recipe |
| B | Vendor-measured figure, labeled | May change a recipe |
| C | Practitioner report with numbers | Inspires; does not found a norm alone |
| D | Opinion without numbers | Color; never "you must" |
| T1 | Fact read in this repo or the installed user guide | Local anchor |

Without **A/B** the pack says **práctica habitual, sin evidencia A/B** — that text is not a performance norm. T1 may change a **local host recipe** (path, key, disable). T1 does not found a “must” on skill size or wording.

A heading in a skill is not a standard. Invented counts ("32 words", "150 characters") stay out. Promote a new gate limit only via `config-quality.md` AC19.

## E1 — SkillsBench (re-anchored 2026-09-10)

Source: arXiv [2602.12670](https://arxiv.org/abs/2602.12670) **v4** (14 Jun 2026), HTML https://arxiv.org/html/2602.12670v4. Level **A**.

| Figure | v4 |

**Product recipe (unchanged):** default template is compact, curated, with evals. One skill = one job. Autogenerated dump is not the default. A bad skill can hurt.

v1 figures from spec seed (86 tasks, 7,308 trajectories, curated +16.2 pp, self-generated −1.3 pp, 16/84 negative, SE +4.5 pp, 2–3 modules +20.0 vs ≥4 +5.2, compact +18.9 vs exhaustive +5.7) are **A (v1 only; not in v4 aggregate)**. Do not mix them with v4 as if they were the same experiment. Do not invent a confidence interval.

## E2 — Anthropic progressive disclosure — B

Metadata always; body on activate; refs on demand. SKILL.md <500 lines. Description = trigger. Eval-first. Hook = guarantee; memory instruction = request.

## E3 — Codex listing — B

Same Agent Skills nucleus. Listing budget 2% of context or 8,000 characters. Load parser does not cap `description`; listing truncates (D29: 1024 portable + listing truncate, not a 500-char error). Extra keys ignored. Optional `agents/openai.yaml`.

## E6 — Gate ≠ performance — A

`config-quality.md`: passing metadata is not a quality score. arXiv 2602.11988v2 (AGENTS.md) and 2601.20404v2 disagree on memory-file payoff. Neither validates an "ideal" description length. Gate numbers come from Agent Skills / the strictest verified host, not taste.
