# T1 — Skill

Shared refs: [lookup.md](lookup.md) · [evidence.md](evidence.md) · [lifecycle.md](lifecycle.md) · [native-creators.md](native-creators.md).
Templates: [reference.md](../templates/skill/reference.md) · [research.md](../templates/skill/research.md) · [workflow.md](../templates/skill/workflow.md).

Load **this pack only** for skill work. Do not load sibling type packs.

## 1. What / when

A skill is a directory with `SKILL.md`: procedural knowledge loaded on demand.

| Choose T1 when | Choose something else |
|---|---|
| A procedure that needs judgement, sometimes | Always-the-same with no judgement → **T5 hook** |
| Too long to retype, too specific for memory | Short always-do → **T9** memory or **T4** rule |
| User or model should invoke it by name | Isolated persona/context → **T3** agent |
| | Slash-only thin prompt, no supporting dir → **T2** command |

Do **not** create a skill when it fits CLAUDE.md/AGENTS.md, belongs in a hook, or is an autogenerated dump ([evidence.md](evidence.md) E1: a bad skill can hurt).

`type` (knowledge-base / workflow / …) is **not** portable. This repo may pick a template flavor; do not write `type:` into frontmatter.

## 4. Min template

Copy one flavor, then instantiate (replace `{{…}}`). Instantiated output must pass `bun run check:config` with **no hand patches**.

| Flavor | File | Use |
|---|---|---|
| reference | `templates/skill/reference.md` | Patterns, conventions, checklists |
| research | `templates/skill/research.md` | Sourced investigation |
| workflow | `templates/skill/workflow.md` | Stepped process; `disable-model-invocation: true` |

Instantiation rules:

- `{{SKILL_NAME}}` = kebab 1–64, **equals** the directory name.
- Keep `{{DESCRIPTION}}` **one line**. It sits in an indented `\|` block; a multiline fill that is not re-indented ends the scalar (`metadata.parse`). Budget the **whole decoded description** (including `Úsala cuando:`) against 1024.
- `description` 1–1024 after YAML decode. This repo: es-ES, third person, qué + cuándo. Foreign repo: portable English (or that repo's language).
- `metadata.keywords` is a **string** (this-repo hook). Empty string disables the description fallback.
- `when_to_use` is a **string**. `argument-hint` is a **string**, not a YAML list.
- Body: when-NOT, content map, ≥3 eval scenarios, anti-patterns.
- Omit Claude-only `context: fork` / `agent:` from the portable default.

## 6. Poneglyph grain

| Axis | Default |
|---|---|
| Quality | Eval-first (≥3 scenarios) on **new** skills in this repo. When-NOT. Description = routing code, not docs. |
| Tokens | SKILL.md short; refs one level; do not load other type packs. Compact beats exhaustive (E1). |
| This repo (AC13) | `description` + `when_to_use` es-ES; `metadata.keywords` for the activation hook; evals. |
| Foreign repo | Portable nucleus only. No es-ES, no keywords requirement. |
| Gate | `check:config` errors block. Description 1–1024. Body ≥500 lines = warning, not failure. No second validator. |

Do not rewrite the existing ~30-skill catalog to this template (D12).
